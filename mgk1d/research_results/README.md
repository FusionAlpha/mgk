# Research Results

This directory contains human-readable scientific outputs, separate from the
solver implementation:

```text
research_results/case_studies/       curated figures, data, and scripts
research_results/benchmark_inputs/   benchmark input decks
```

Start with [case_studies/README.md](case_studies/README.md). The categorized
historical `figures/` directory and local `analysis/` workspace are retained
as history; new reportable results should go into a named case under
`case_studies/`.
