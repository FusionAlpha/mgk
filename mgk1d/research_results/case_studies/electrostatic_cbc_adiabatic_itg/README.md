# Electrostatic CBC: Adiabatic-Electron ITG

This is the Cyclone Base Case electrostatic ITG scan with adiabatic electrons.
The checked-in result is generated by the Python CPU-double solver.

## Model and grid

- `s-alpha` geometry: `q=1.4`, `s_hat=0.8`, `alpha=0`
- kinetic main ions, adiabatic electrons, collisionless
- open ballooning boundary, `theta = [-4 pi, 4 pi]`
- `R/Ln=2.2`, `R/LTi=6.9`, `Ti=Te=1000 eV`, `B=2 T`
- `k_y rho_s = 0.05, 0.10, ..., 0.65`
- production grid: `Ntheta=129`, `NE=28`, `Npitch=32`, `Nbounce=48`

## Files

- `figures/cbc_adiabatic_itg_dispersion.png`: report-ready dispersion plot.
- `data/python_cpu_dispersion.csv`: Python CPU-double values and timings.
- `scripts/run_adiabatic_itg.py`: Python reproduction script.

The CSV columns include normalized real frequency, growth rate, eigen residual,
field residual, and wall time. Numerical residuals and grid parameters are
recorded in [BENCHMARK_CASES.md](../../../BENCHMARK_CASES.md).

## Reproduce

From the repository root:

```bash
PYTHONPATH=. python3 research_results/case_studies/electrostatic_cbc_adiabatic_itg/scripts/run_adiabatic_itg.py
```

The command writes a fresh CSV to this case's `data/` directory. The full
production scan can take several minutes on CPU; use the checked-in CSV for
quick inspection.
