# Paper Physics Cases

This archive contains the scripts and vector figures used by the physical
validation sections of the paper *Sub-Second Collisionless Gyrokinetic
Eigenvalue Solutions via Orbit-Invariant Decomposition*.

Each case directory contains the corresponding PDF vector figure and one
figure-build entry point. Numerical run and validation artifacts have been
removed from the archive.

| Case | Description | Figure |
| --- | --- | --- |
| `01_salpha_itg_eta` | Adiabatic-electron ITG versus `eta_i` in circular s-alpha geometry. | `salpha_itg_eta_cgyro_mgk.pdf` |
| `02_cbc_kinetic_itg_tem` | Kinetic-electron CBC ITG/TEM branch competition and Rewoldt mode comparison. | `cbc_kinetic_itg_tem_branches.pdf` |
| `03_strong_gradient_tem` | Strong-gradient kinetic-electron TEM mode comparison. | `salpha_strong_gradient_tem_mode_cgyro_mgk.pdf` |
| `04_miller_triangularity_itg` | Adiabatic-electron Miller ITG triangularity scan. | `miller_itg_triangularity_cgyro_mgk.pdf` |
| `05_miller_tem_domain` | Circular-Miller kinetic-electron TEM and parallel-domain comparison. | `miller_tem_domain_cgyro_mgk.pdf` |
| `06_xie_em_cbc` | Xie et al. electromagnetic CBC two-field benchmark. | `xie2016_electromagnetic_cbc_benchmark.pdf` |
| `07_shen_em_kbm` | Shen et al. large-aspect-ratio electromagnetic KBM benchmark with two- and three-field calculations. | `shen2025_electromagnetic_kbm_benchmark.pdf` |

Performance-only figures and scripts from the paper are not included here.

Each case directory contains a one-click figure-build entry point for its
corresponding paper figure.
