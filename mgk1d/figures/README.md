# Historical Figure Archive

This directory contains the historical flat figure collection reorganized by
physics case and diagnostic purpose. New report-ready results should be added
to a named directory under `research_results/case_studies/` instead.

```text
figures/electrostatic_cbc_itg_tem/       CBC ITG/TEM dispersion and mode scans
figures/electrostatic_rewoldt2007/       Rewoldt 2007 and CGYRO comparisons
figures/electromagnetic_xie2016_kbm/     Xie 2016 electromagnetic KBM results
figures/gene_mgk_comparisons/            GENE/MGK stability comparisons
figures/numerical_stability_diagnostics/ theta, boundary, branch, and mirror checks
```

The files here are retained for historical reports and local analysis. The
curated copies intended for reuse are documented in
`research_results/case_studies/`.
